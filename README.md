## 📂 Projects & Portfolio

Here are some practical projects demonstrating my capabilities across data analytics, software development, and workflow automation.

### 📊 Data Analytics Projects

**1. [Data Job Market Analysis](https://github.com/SalaamRasak/DataJobMarket)**

A Python-based data analytics project investigating the United States data job market, covering data analyst, data scientist, and data engineering roles. The project uses Pandas, NumPy, Matplotlib, and Seaborn for data processing, exploratory analysis, and visualisation to generate insights useful to job seekers and industry observers.

**2. [Market Analysis](https://github.com/SalaamRasak/marketAnalysis)**

A market research and analytical project leveraging Python and Stata for data processing and analysis.

### 🤖 AI Automation & Software Development Projects

**3. [n8n WordPress News Website Automation](https://github.com/SalaamRasak/News_Workflow)**

An automated content publishing workflow that collects news articles through RSS feeds, filters content using keywords and publication timing, and enhances selected articles with OpenAI. JavaScript handles workflow logic, MongoDB supports data storage, and WordPress manages automated publishing, with email notifications integrated into the process.

**4. [Make.com Food Restaurant Automated Workflow](https://github.com/SalaamRasak/AI_Automation_Workflow)**

An automated restaurant order-processing system integrating HTML5, CSS3, JavaScript, webhooks, Google Sheets, and Make.com. It captures customer orders, processes submissions, applies conditional routing, and delivers notifications through Telegram, WhatsApp, and Gmail.

**5. [Automated Custom Form for Data Pipelines](https://github.com/SalaamRasak/Custom_Food_Ordering)**

A custom-built web form developed with HTML5, CSS3, and JavaScript and integrated with webhooks for structured data collection and real-time workflow responses.
